## Interaction Quality Scorecard

| Criteria | Score | Evidence |
|---|---|---|
| **Trust building** | ✅ Strong / ⚠️ Adequate / ❌ Weak | Did tester listen first before pitching? Did they acknowledge existing systems? |
| **Trigger avoidance** | ✅ Clean / ⚠️ Near-miss / ❌ Hit | Any persona shutdown at specific topics? M&A, AI, AMS replacement, etc.? |
| **Persona consistency** | ✅ Accurate / ⚠️ OK / ❌ Off | Did the persona feel real? Namedropping staff? Dollar amounts? Local knowledge? |
| **Objection handling** | ✅ Good / ⚠️ OK / ❌ Poor | How was skepticism met? Past vendor failures acknowledged? |
| **Pacing** | ✅ Natural / ⚠️ Rushed / ❌ Too slow | Did tester let persona dictate pace or push too fast? |
| **Specificity** | ✅ Concrete / ⚠️ Generic / ❌ Vague | Dollar amounts, timelines, named carriers/people mentioned? |
