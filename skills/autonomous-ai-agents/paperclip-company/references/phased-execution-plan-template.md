## Plan Index Format (plan/README.md)

The plan index should contain:

1. **How to read phases** — table explaining each section's meaning
2. **Phase table** — all phases with timeframe, focus, clients, MRR, human time
3. **Roadmap** — ASCII timeline showing months, phases, layers, clients, MRR
4. **Operating rhythm** — daily/weekly/monthly/quarterly cadence table
5. **Escalation path** — normal/exception/failure mode flow
6. **Start here** — link to Phase 1
